# M7 — Notifications

**Status:** implemented (PR pending)  
**Prompt:** `prompts/M7.md`  
**Handoff:** `docs/handoffs/M7_HANDOFF.md`

## Goal
Reliable, privacy-safe, independently configurable local reminders with WorkManager, discreet modes, contextual permission UX, cycle/appointment/pregnancy weekly reminders, timezone replanning, and backend push-token foundations.

## Delivered (this milestone)
- `:domain:reminders` schedule planner + tests
- DataStore notification preferences (privacy mode + per-category opt-in)
- `:core:notifications` WorkManager workers, replan coordinator, timezone receiver, notification presenter
- Today → notification settings UI with POST_NOTIFICATIONS permission flow
- Backend `V5__notifications_push.sql`, push-token API (hashed at rest), NoOp dispatcher
- OpenAPI + ADR 0014

## Exit criteria
Reminders are reliable, privacy-safe, and independently configurable (see handoff acceptance table).

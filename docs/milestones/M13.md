## Goal
Finish visual and interaction quality on **priority Android surfaces** without changing backend behavior or feature-flag defaults.

## In scope (polished)
- **Today** — headers, prediction/status cards, grouped settings
- **Log** — section labels, choice chips, screen header
- **History** — single lazy list, surface cards, empty state
- **Cycle calendar** — visual legend, extracted testable content
- **Onboarding** — welcome through pregnancy setup
- **Design system** — `MahinScreenHeader`, `MahinSurfaceCard`, `MahinChoiceChip`, `MahinCalendarLegend`, `MahinSettingsGroup`
- Demo/placeholder screens moved to **debug** source set (not in release APK)

## Out of scope (deferred)
- Full polish of Insights, TTC hub, Pregnancy hub, Learn, export flows, notification settings UI
- Health Connect / AI assistant enablement
- Backend, OpenAPI, migrations

## Exit criteria
- Priority screens use shared tokens/components
- RTL + a11y tests for polished surfaces
- Demo screens not on primary user path
- CI green on PR head

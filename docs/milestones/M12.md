## Goal
Architecture ready for **controlled AI experimentation** — not an unrestricted medical assistant at GA.

## Delivered
- Remote kill switch `health_assistant` on `/v1/meta` (default **off**)
- Backend assistant gateway, keyword retrieval + fixture corpus, citations, consent API, escalation engine, metadata-only audit log (Flyway **V8**)
- Deterministic fake provider (local/test/dev profiles only); OpenAI adapter **prepared, not executed**
- CI evaluation harness (Persian safety/grounding fixtures)
- Android consent UI gated by flag; `HealthAssistantGateway` domain boundary + Retrofit client via `MAHIN_API_BASE_URL`
- OpenAPI `/v1/assistant/*`; privacy/compliance doc updates

## Honest exit
Infrastructure and tests are in place. **Production enablement** remains blocked on: clinical corpus, signed escalation rules, legal consent copy, vendor keys/DPA, and explicit flag + provider configuration.

## Next milestone
None — post-GA experimentation / enablement gates only.

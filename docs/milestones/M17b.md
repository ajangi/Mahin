# M17b — Android Learn magazine, daily tip, session player, Coil

**Status:** Implemented in PR (Android UI + client wiring on M17a APIs).  
**Next milestone:** **M18a** only.

## Scope delivered

- Extended hand-maintained `ContentApi` and `ContentRepository` for daily tips, programs, collections, articles, and media metadata.
- Learn magazine UI (featured collections, category chips, contextual rail, programs, search, bookmarks, recent views).
- Article reader with source/review footer; program detail with CMS safety block; guided session player with timer, pause/resume, process-death restore, local completion counts.
- Today daily tip card (dismissible; hidden when empty/offline without cache).
- Coil remote illustrations via `CmsMahinIllustrationSource`, bounded disk cache, medical gating, offline frame fallback.
- Room v8 additive tables for article/media cache, recent views, player state, session completions.

## Deferred

- Premium collection gating (owner: all collections FREE for now).
- Optional program reminder wiring through reminders domain.
- Clinical/production CMS content (placeholders only).

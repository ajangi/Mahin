# M5 — Backend Identity & Sync

**Status:** implemented (PR pending)  
**Prompt:** `prompts/M5.md`  
**Handoff:** `docs/handoffs/M5_HANDOFF.md`

## Goal
Production backend foundations for guest identity, optional accounts, device sessions, outbox sync with idempotency and deterministic conflicts, guest conversion, and deletion/export job stubs.

## Delivered
- Flyway `V2__identity_sync.sql`
- Auth (register/login/refresh/logout), guest bootstrap, guest conversion
- Sync push/pull with `SyncConflictResolver` + integration tests
- Device list/heartbeat
- Privacy deletion/export job queue endpoints
- OpenAPI + ADR 0012

## Exit criteria
Offline-first multi-session synchronization passes deterministic backend integration scenarios without data loss/duplication (see handoff).

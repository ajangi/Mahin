# Learn magazine (M17b)

## Regions
- Top: title + educational disclaimer
- Search field + action
- Category chips (all + seven CMS categories)
- Featured collections carousel
- Contextual “for your phase/week” article rail
- Guided programs rail
- Recently viewed rail

- Loading: indeterminate progress
- Populated: rails per above
- Offline/empty: `MahinEmptyState` when no cached magazine data

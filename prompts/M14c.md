# M14c Cloud Agent Prompt — App Shell & Settings

## Authority
Follow `AGENTS.md`, `docs/PRD.md` §5, `docs/DESIGN_SYSTEM.md`, `docs/PROGRAM_V2_PLAN.md` §3. Read `docs/handoffs/M14b_HANDOFF.md` and the shell/Settings specs from M14a. This prompt scopes the current implementation; the PRD remains authoritative.

## Problem
`MahinTopLevelDestination.forMode` returns 6 tabs for TTC and Pregnancy, and none of the modes match PRD §5. Settings live inside the Today screen.

## Scope
1. **Bottom navigation per PRD §5 (exactly 5 tabs per mode)**, using the M14b `nav` icons and a Mahin bottom bar (selected-state pill, restrained mode accent, Mulberry identity unchanged):

| Mode | Tabs |
|---|---|
| `CYCLE_TRACKING` | Today · Calendar · Log · Insights (cycle) · Learn |
| `TRYING_TO_CONCEIVE` | Today · Calendar · Log · Insights (TTC) · Learn |
| `PREGNANT` | Today · Pregnancy · Log · Plan · Learn |
| `POST_PREGNANCY_TRANSITION`, `TRACKING_PAUSED` | Today · Calendar · Log · Insights (cycle) · Learn |

2. **History** stops being a tab. It becomes a secondary screen (with up navigation) reached from Insights (cycle and TTC; extend the existing `onOpenHistory` entry), from the Pregnancy tab ("past cycles"), and from Settings › Your data.
3. **Pregnancy tabs.**
   - **Pregnancy** = the existing Pregnancy hub (status, week card slot, kick counter, contraction timer, outcome).
   - **Plan** = a new screen hosting the existing appointments section, extracted from the hub with no behaviour change. M18 extends it.
   - The cycle calendar is not a pregnancy tab. In pregnancy mode it stays reachable from a Pregnancy-tab entry; M15 adds the Today week-strip entry.
4. **Top app bar** with a profile/settings entry (PRD §5) on every top-level screen.
5. **Settings screen** with groups: tracking goal (the existing mode card, mode changes still explicit), privacy & security, notifications, backup & account (existing M5 entry points only; no new sync behaviour), data export, Health Connect (only when its flag is on), assistant (only when its flag is on), and about. **Remove the settings group and mode card from Today.**

## Execution rules

- No new persistence, sync or OpenAPI changes.
- Keep RTL-native navigation, accessibility, privacy and sensitive-screen protections intact.

## Acceptance criteria
- Unit test: `forMode` returns exactly the tabs in the table above for every `ReproductiveMode`.
- Navigation tests: each tab navigates and restores state; History is reachable from Insights (cycle/TTC), the Pregnancy tab and Settings; back/up behaviour is correct; the debug-only demo routes stay out of release.
- Today no longer contains the settings group or mode card. Every relocated entry works from Settings (UI tests).
- Accessibility: tabs expose selected state and localized labels; touch targets ≥ 48 dp; TalkBack order is correct in RTL.
- Goldens (M14a harness, light/dark × 1.0/1.3, RTL) for the shell in each mode and for Settings, under `<module>/src/test/screenshots/`. `verifyRoborazziDebug` passes in CI.
- All existing checks pass.

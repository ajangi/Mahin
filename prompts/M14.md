# M14 Cloud Agent Prompt — Visual Identity, Icon Set, Illustration Pipeline & App Shell

## Authority
Follow `AGENTS.md`, `docs/PRD.md`, `docs/DECISIONS.md`, `docs/DESIGN_SYSTEM.md`, `docs/ILLUSTRATION_SYSTEM.md` and `docs/PROGRAM_V2_PLAN.md` (especially §3 Quality bar). Read `docs/handoffs/M13_HANDOFF.md` first.

## Problem
The app ships one drawable (the launcher icon). The navigation bar uses stock Material icons, and screens have no visual anchor. Every later V2 milestone depends on the assets and components built here.

## Scope
1. **Screen spec framework.** Create `docs/design/screens/` with a spec template covering regions, states, copy keys, tokens, motion and a11y. Write specs for the app shell, Today, Calendar and Log, to be implemented in M15/M16.
2. **Original Mahin icon set** (Android vector drawables, `core:designsystem`, family `symptom/*`, `mood/*`, `flow/*`, `nav/*`, `action/*`). Follow the illustration visual language: rounded organic geometry, a consistent 24 dp grid, 1.75 dp stroke, a Mulberry line plus one semantic accent, and no embedded text. Minimum coverage: every PRD §7.3 symptom and mood, flow levels spotting through very heavy, discharge types, sex/protection, tests (OPK, pregnancy, BBT), sleep, water, weight, medication, exercise, and the five nav destinations for each mode. These are **non-medical UI icons** and allowed under `ILLUSTRATION_SYSTEM.md`. Do not trace or reproduce any competitor artwork.
3. **Illustration slot pipeline.** Add a `MahinIllustration(assetId, decorative|contentDescription)` composable backed by `core:media`. It resolves stable semantic IDs (e.g. `editorial/today/empty/v1`) to a bundled vector or a CMS-provided remote asset, with a bounded cache and graceful fallback. Ship clearly labelled neutral placeholder art (abstract shapes in tokens, with a `placeholder=true` flag in metadata) for empty states and editorial slots. Medical-governed IDs must render nothing, or a neutral frame, unless the CMS metadata says `approved`.
4. **Motion tokens.** Add durations/easings to `design/tokens.json`, plus a `LocalReducedMotion` helper that honours the system animator scale.
5. **Typography.** Implement the Numeric Display role for big tracking numbers (`۲۸`, `هفته ۲۱`) with Persian digits and tabular figures.
6. **Dark theme semantic variants.** Add dark variants for period/fertility/ovulation/pregnancy/status with automated contrast tests. Changing brand tokens requires an ADR.
7. **App shell.** Replace the stock `NavigationBar` with a Mahin bottom bar (custom icons, selected-state pill, mode accent) and add a top app bar with profile/settings entry per PRD §5. Move settings out of the Today screen into a proper Settings screen (privacy, notifications, backup, export, Health Connect, assistant, about).

## Out of scope
Today/Calendar/Log screen content redesign (M15/M16). Final illustrations. Backend changes.

## Acceptance
- Icon set is complete per the list above, and a debug-only icon catalogue screen renders every icon with its ID.
- Full-screen Roborazzi goldens for the shell + Settings in light/dark, RTL, at font scales 1.0 and 1.3 under `docs/design/goldens/M14/`.
- `check_design_tokens.py` passes. No hex colours in feature code.
- Contrast tests pass for all dark semantic colours.
- All existing checks pass (see M13 handoff command list).
- `docs/handoffs/M14_HANDOFF.md` and `docs/milestones/M14.md` written. STOP after M14.

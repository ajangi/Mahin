# M17 Cloud Agent Prompt — Daily Wellness, Learn Magazine & Guided Programs

## Authority
Follow `AGENTS.md`, `docs/PRD.md` §10–11, `docs/MEDICAL_CONTENT_GOVERNANCE.md`, `docs/ILLUSTRATION_SYSTEM.md`, `docs/PROGRAM_V2_PLAN.md`. Read `docs/handoffs/M16_HANDOFF.md` and ADR 0013.

## Problem
Yekzan's daily tips, yoga/fitness and Kegel programs keep users opening the app. Mahin has only an article list.

## Hard rule
Agents build **content types, workflow, delivery and UI**. Agents must **not** author tips, exercise instructions or medical guidance as real content. Seed data is clearly marked placeholder (`placeholder=true`, visible "نمونه" badge in debug builds, excluded from release seed).

## Scope
### Backend / CMS (modular monolith, existing content module)
- New content types with full review workflow, versioning, reviewer/provenance and risk level:
  - `daily_tip` — targeting by mode, cycle phase, pregnancy week and locale; validity window.
  - `program` — an ordered list of sessions; each session has steps (instruction text key, duration, rep count, rest, optional media asset ID). Types: `pelvic_floor` (Kegel), `movement` (yoga/stretch), `breathing`.
  - `collection` — curated article groups for the Learn magazine.
- Admin UI (Vite/React) editors and review screens for these types.
- OpenAPI updated. Migrations added.

### Android
- **Learn magazine**: hero collection carousel, category chips (Cycle / Fertility / Pregnancy / Symptoms / Nutrition / Tests / Lifestyle), a contextual "for your week/phase" rail, article reader with source/review footer, bookmarks, recently viewed (local), Persian-normalised search. Offline cache for previously opened articles and media.
- **Daily tip** card on Today (slot from M15), shown only for approved content, and dismissible.
- **Guided session player**: step timer, haptic + optional sound pacing for contract/relax (Kegel), pause/resume, completion log (local; counts only, no health inference), optional reminder via the existing reminders domain with discreet wording.
- Contraindication/safety notice block rendered from CMS fields on program start. Never hard-coded.

## Acceptance
- CMS review workflow tests: unapproved tips/programs are never served by the public API.
- Android: tip slot hidden when the API returns none, and offline behaviour verified.
- Player unit tests for deterministic step timing, including pause/resume and process death.
- Full-screen goldens for Learn home, article, program detail and player.
- All existing checks pass. Handoff lists the clinical content needed before launch. STOP after M17.

# M17 Cloud Agent Prompt — Daily Wellness, Learn Magazine & Guided Programs

> **To be split before execution** (plan §5): **M17a** covers backend/CMS/admin/OpenAPI for `daily_tip`, `program` and `collection`. **M17b** covers the Android Learn magazine, daily tip card, session player and Coil remote image loading. Execute one part per PR.

## Authority
Follow `AGENTS.md`, `docs/PRD.md` §10–11 and §13, `docs/MEDICAL_CONTENT_GOVERNANCE.md`, `docs/ILLUSTRATION_SYSTEM.md`, `docs/PROGRAM_V2_PLAN.md`. Read the latest handoff and ADRs 0005 and 0013. This prompt scopes the current implementation; the PRD remains authoritative.

## Scope
### Backend / CMS / admin (M17a)
- New content types in the existing content module of the modular monolith, each with the full review workflow, versioning, reviewer/provenance and risk level:
  - `daily_tip` — targeting by mode, cycle phase, pregnancy week and locale; validity window.
  - `program` — ordered sessions; each session has steps (instruction text, duration, reps, rest, optional media asset ID) and CMS-authored contraindication/safety fields. Types: `pelvic_floor` (Kegel), `movement` (yoga/stretch), `breathing`.
  - `collection` — curated article groups for the Learn magazine.
- Admin (Vite/React) editors and review screens for these types.
- Public API returns only approved, published items. OpenAPI updated and linted. Database migrations added.

### Android (M17b)
- **Remote CMS images**: implement the `MahinIllustration` remote source from M14b using Coil behind `core:media`. Bounded disk cache, offline fallback to the neutral frame, and no user data in image URLs. Medical gating from M14b still applies.
- **Learn magazine**: hero collection carousel, category chips (Cycle / Fertility / Pregnancy / Symptoms / Nutrition / Tests / Lifestyle), a contextual "for your phase/week" rail, an article reader with a source/review footer, bookmarks and recently viewed (local), and Persian-normalised search. Previously opened articles and media are cached for offline use.
- **Daily tip card** fills the M15 Today slot only with approved content. It is dismissible and hidden when there is none.
- **Guided session player**: step timer, haptic and optional sound pacing for contract/relax, pause/resume that survives process death, and a local completion log (counts only, no health inference). Optional reminder via the existing reminders domain, with discreet wording.
- The safety/contraindication block is rendered from CMS fields when a program starts. It is never hard-coded.

## Execution rules
- Implement **one split part (M17a or M17b) per PR**, in order.
- Agents build content types, workflow, delivery and UI. **Agents must not author tips, exercise instructions or medical guidance as real content.** Seed data is marked `placeholder = true`, shows a "نمونه" badge in debug builds, and is excluded from release seeds.
- Safety notices and essential safety information are never paywalled (PRD §13).
- Additive migrations only; keep OpenAPI and implementation in sync.
- No content-consumption events that reveal health state in analytics. `SensitiveAnalyticsGuardTest` must cover any new events.
- Run relevant format, lint, static analysis, unit/integration/UI tests and builds before completion.

## Out of scope
- Real clinical content (authored and reviewed by the content team before launch).
- Nutrition/meal programs (M22, gated).
- AI-generated content or recommendations.

## Acceptance criteria
- Backend tests: unapproved or expired tips, programs and collections are never served by the public API. Workflow transitions are enforced.
- Admin tests cover the editors and review actions for each new type.
- `npx @redocly/cli lint openapi/openapi.yaml` passes.
- Android: the tip slot is hidden when the API returns nothing and when offline with no cache (tests).
- Remote images: cache, offline fallback and medical gating covered by tests; no user identifiers in requested URLs (test).
- Player unit tests cover deterministic step timing, pause/resume and process-death restore.
- Goldens (light/dark × 1.0/1.3, RTL) under `<module>/src/test/screenshots/` for Learn home, article, program detail and player. `verifyRoborazziDebug` passes.
- All existing checks pass.

# M18 Cloud Agent Prompt — Pregnancy Companion Depth

## Authority
Follow `AGENTS.md`, `docs/PRD.md` §9, `docs/MEDICAL_CONTENT_GOVERNANCE.md`, `docs/ILLUSTRATION_SYSTEM.md`, `docs/PROGRAM_V2_PLAN.md` §4. Read `docs/handoffs/M17_HANDOFF.md` and ADR 0011.

## Scope
1. **Week-by-week hero**: illustration slot (`pregnancy/fetal-development/week-N/vX`, shown only when CMS metadata is `approved`; otherwise a neutral frame + text), size comparison labelled "مقایسهٔ تقریبی و سرگرم‌کننده" (PRD §9.1), fetal and maternal summaries from CMS, and swipe between weeks.
2. **Pregnancy timeline**: CMS `care_schedule` content type (recommended tests/ultrasounds by gestational-week window, reviewed, Iran-context) merged with user appointments on one timeline. Educational framing: "according to your care plan". One-tap "add as appointment".
3. **Tools hub** (public, also usable before pregnancy): due-date calculator and gestational-age calculator (LMP / ultrasound / conception) reusing `domain:pregnancy`. These are calculators only and are not persisted unless the user starts pregnancy mode.
4. **Hospital-bag checklist**: a CMS `checklist_template` (reviewed) that the user copies into a local, editable checklist with progress.
5. **Pregnancy expense tracker**: local-first ledger (category, amount in Toman/Rial with Persian digits, Jalali date, note). Synced via the outbox only if the account sync opt-in covers it. Includes summary by category. Never sent to analytics.
6. **Warning signs & BP**: replace "poisoning test" ideas with a reviewed warning-signs card (CMS) and BP log flagging that uses **only** reviewed thresholds from CMS/config, with escalation copy to seek care. No risk score and no diagnosis.
7. **Weight gain chart**: user-logged weight over weeks. Reference bands only if reviewed content provides them.
8. Polish kick counter and contraction timer UI to the V2 quality bar.

## Out of scope
Fetal sex prediction and eye-colour prediction (declined pending owner confirmation, `PROGRAM_V2_PLAN.md` §7). Postpartum (M19).

## Acceptance
- Unit tests: calculators match existing dating rules, timeline merge ordering, and expense totals with Persian formatting.
- Migrations for checklist and expense tables with tests.
- No warning/threshold value is hard-coded in Android; a test asserts thresholds come from the config/CMS source.
- Full-screen goldens for the pregnancy home, week view, timeline, tools, checklist and expenses.
- All existing checks pass. Handoff and milestone docs written. STOP after M18.

# M22 Cloud Agent Prompt — Nutrition Programs

> **GATED.** Requires owner approval (`docs/PROGRAM_V2_PLAN.md` §7 item 5) and a qualified dietitian content source. Agents must not generate diets or meal plans as real content. If unapproved, STOP and report.

## Authority
`AGENTS.md`, `docs/PRD.md` §10, `docs/MEDICAL_CONTENT_GOVERNANCE.md`. Read `docs/handoffs/M17_HANDOFF.md` and the latest handoff.

## Scope (once approved)
- CMS `meal_program` type extending M17 programs: days → meals → items (Persian foods, portions), with contraindications, target context (general, PCOS, TTC, pregnancy, lactation, vegetarian/vegan, etc.), reviewer/provenance, and risk level. Pregnancy/lactation/PCOS programs are high-risk and require clinician review.
- Android: program catalogue filtered by current mode, onboarding questions limited to what the program needs (no calorie targets without a reviewed formula), daily plan view, shopping list, swap alternatives defined in CMS, and local adherence check-offs.
- Premium gating allowed only for non-essential programs (PRD §13). Safety notices are never paywalled.

## Acceptance
Unapproved programs never served; no calorie/medical computation outside reviewed config; full-screen goldens; handoff. STOP after M22.

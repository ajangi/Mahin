# M15 Cloud Agent Prompt — Today Home & Calendar Redesign

## Authority
Follow `AGENTS.md`, `docs/PRD.md`, `docs/DECISIONS.md`, `docs/DESIGN_SYSTEM.md`, `docs/ILLUSTRATION_SYSTEM.md`, `docs/PROGRAM_V2_PLAN.md` §3. Read `docs/handoffs/M14_HANDOFF.md` and the Today/Calendar screen specs from M14.

## Problem
Today currently shows an empty-state sentence and a settings card. Users need to understand their day in a single glance.

## Scope
### Today (Cycle / TTC)
- **Cycle ring hero**: an arc showing cycle progress, with segments for logged period, predicted period, estimated fertile window and estimated ovulation. Predicted segments must be visually distinct (dashed/hatched) from logged ones. The centre shows the day of cycle in Numeric Display ("روز ۱۴") and a status line ("۵ روز تا پریود بعدی (تخمینی)"). Low-confidence predictions show a confidence chip with an explanation sheet.
- **Week strip** (Jalali, swipeable) under the hero; tapping a day opens the day sheet.
- **Quick-log row**: period started/ended, symptoms, mood, and a TTC-only test. One tap opens the M16 day editor; until M16, open the current Log screen.
- **Today's logged summary** as icon chips.
- **Daily tip card slot** (CMS-driven in M17; hidden when no approved tip exists — never a hard-coded tip).
- **Upcoming card**: next reminder or appointment.
- **Empty/first-day state** with a placeholder illustration and a single clear CTA ("ثبت اولین پریود").

### Today (Pregnancy)
- Week ring: gestational age "هفته ۲۱ + ۳ روز", trimester, EDD countdown, dating source chip. Plus a week card slot (CMS), upcoming appointment, and kick/contraction quick actions.

### Calendar
- Month view with day cells showing shape + colour (filled = logged, outlined/dashed = predicted, dot = log entries, ring = today). Jalali primary, Gregorian in the day sheet.
- **Day sheet** (modal bottom sheet) with a shared-element transition from the cell: the day's logs, prediction state with an explanation, and an edit action.
- A legend that collapses after first use.
- Smooth month paging and a jump-to-today action.

### Domain
- Add a pure domain use case `TodaySnapshot` in `domain:cycle`/`domain:pregnancy` that composes existing prediction output into the hero model. It must be deterministic and unit-tested, including irregular/insufficient-data cases. No new prediction math.

## Out of scope
New prediction algorithms, the log editor (M16), CMS content types (M17).

## Acceptance
- Full-screen goldens for Today (empty, early cycle, fertile window, late/overdue period, low confidence, pregnancy week) and Calendar (month, day sheet) in light/dark, RTL, at font scales 1.0 and 1.3.
- Macrobenchmark: Today first frame ≤ 500 ms on the reference device profile. Report the result.
- TalkBack reads the ring as a sentence, e.g. "روز ۱۴ چرخه، پریود بعدی حدود ۵ روز دیگر، تخمینی".
- No copy implies certainty, contraception safety or diagnosis.
- All existing checks pass. Handoff and milestone docs written. STOP after M15.

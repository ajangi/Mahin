# M15 Cloud Agent Prompt — Today Home & Calendar Redesign

## Authority
Follow `AGENTS.md`, `docs/PRD.md` §5, §7.1, §7.4 and §9.1, `docs/DESIGN_SYSTEM.md`, `docs/ILLUSTRATION_SYSTEM.md`, `docs/PROGRAM_V2_PLAN.md` §3. Read `docs/handoffs/M14c_HANDOFF.md` and the Today/Calendar specs from M14a. This prompt scopes the current implementation; the PRD remains authoritative.

## Problem
Today shows an empty-state sentence. Users need to understand their day in a single glance.

## Scope
### Today (Cycle / TTC / post-pregnancy / paused)
- **Cycle ring hero.** An arc showing cycle progress, with segments for logged period, predicted period, estimated fertile window and estimated ovulation. Predicted segments must be visually distinct (dashed/hatched) from logged ones, not just a lighter shade.
  - Centre: day of cycle in Numeric Display ("روز ۱۴").
  - Status line, e.g. "۵ روز تا پریود بعدی (تخمینی)".
  - Low-confidence or insufficient-data states show a confidence chip with an explanation sheet.
- **Fertile-window wording** must say these are estimates and **not a contraception method** (PRD §7.4), both on Today and in the explanation sheet. Never "safe days".
- **Week strip** (Jalali, swipeable) under the hero. Tapping a day opens the calendar day sheet.
- **Quick-log row**: period started/ended, symptoms, mood, and a TTC-only test. Until M16, each opens the existing Log screen for that day.
- **Today's logged summary** as icon chips (M14b icons).
- **Daily tip slot**: an empty container that M17 fills from the CMS. In M15 it is always hidden; never a hard-coded tip.
- **Upcoming card**: next scheduled reminder (existing reminders domain).
- **First-day state**: a placeholder illustration (`MahinIllustration`) and one clear CTA ("ثبت اولین پریود").

### Today (Pregnancy)
- **Week ring**: gestational age "هفته ۲۱ + ۳ روز", trimester, EDD countdown and a dating-source chip.
- Week card slot (CMS; neutral when no approved content).
- Upcoming appointment card that opens the **Plan** tab (M14c).
- Kick counter / contraction timer quick actions that open the **Pregnancy** tab.
- A week-strip entry to the cycle calendar. This matches M14c: the calendar is not a pregnancy tab.

### Calendar
- Month view where each day cell uses shape plus colour: filled = logged, outlined/dashed = predicted, dot = log entries, ring = today. Jalali is primary; Gregorian appears in the day sheet.
- **Day sheet** (modal bottom sheet) with a shared-element transition from the cell. It shows the day's logs, the prediction state with an explanation (including non-contraception wording on fertile days), and an edit action.
- A legend that collapses after first use (local preference).
- Smooth month paging and a jump-to-today action.

### Domain
- Add a pure `TodaySnapshot` use case (in `domain:cycle` / `domain:pregnancy`) that composes **existing** prediction and dating output into the hero model. It must be deterministic and unit-tested, including irregular, insufficient-data, overdue and pregnancy cases. No new prediction math.

## Execution rules
- Implement **M15 only**.
- No new prediction algorithms; no change to `algorithm_version` semantics.
- No copy may imply certainty, contraception safety or diagnosis. Never infer pregnancy from a late period.
- Respect `LocalReducedMotion` for ring fill and shared-element transitions.
- No persistence changes except a local UI preference for legend collapse (DataStore).
- Keep RTL, accessibility and privacy intact. No cycle dates in logs or analytics.
- Run relevant format, lint, static analysis, unit/UI tests and builds before completion.

## Out of scope
- The day editor bottom sheet (M16).
- CMS tip and week content types (M17/M18).
- Real-device performance targets (human follow-up per plan §3).

## Acceptance criteria
- `TodaySnapshot` unit tests cover regular, irregular, insufficient-data, overdue, fertile-window and pregnancy-week cases.
- Goldens (light/dark × 1.0/1.3, RTL) under `<module>/src/test/screenshots/` for Today (first-day, early cycle, fertile window, overdue, low confidence, pregnancy week) and Calendar (month, day sheet). `verifyRoborazziDebug` passes in CI.
- TalkBack reads the ring as one sentence, e.g. "روز ۱۴ چرخه، پریود بعدی حدود ۵ روز دیگر، تخمینی".
- Fertile-window UI shows non-contraception wording (UI test asserts the string is present).
- In pregnancy mode the calendar is reachable from Today and the Pregnancy tab, and is not a tab.
- Benchmark: the Today first-frame macrobenchmark from M14a is updated for the new screen. Emulator numbers are reported in the handoff if an emulator is available; the module compiles in CI.
- All existing checks pass.
